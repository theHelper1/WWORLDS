# WWORLDS

Wedding planning studio: find vendors, message in real time, sign contracts, and settle **USD → XRP → USD** on Instant Rail.

Couples pay the listed fiat amount. Vendors pay a **2.9%** Instant Rail processing fee.

## Demo

```bash
npm install
npm run db:setup
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
